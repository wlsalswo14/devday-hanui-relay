# 개발 범위와 자료 출처

기록일: 2026-10-09.

기존 Hanui RAG 시스템의 코드는 이 저장소에 가져오지 않았다. 고문헌 수집·정리는 사용자의 요청에 따라 OpenAI GPT-6 Luna / xhigh 서브에이전트에게 위임했다. 서비스 모델은 Luna / high다. 질문에서 검색 키워드를 모델이 정하고, SQLite의 수록 원문·독해·메타데이터 전문을 서버가 탐색한 뒤 모델이 관련 문장과 항목을 정리한다. 인용 문자열과 DB 본문을 대조하여 정확한 위치를 계산한다.

## Codex 활용과 검토

- 구현과 자료 수집에는 OpenAI 모델만 사용했다.
- 서비스의 대화 모델은 기존 ChatGPT 로그인으로 호출하는 GPT-6 Luna, 추론 강도 high다.
- 병원·공개 후기·웹 검색도 같은 Luna High와 OpenAI 웹 검색으로 실행한다. 다른 제공자의 AI나 서브 에이전트로 전환하지 않는다.
- 질문 분석·DB 답변은 셸·웹·플러그인 없이 동작하며, 외부 검색은 대화에서 모델이 필요한 공개 정보 검색어를 고른 뒤 실행한다. 별도 병원·웹 검색 화면 없이 대화에 결과를 표시한다. 체크인·목표는 검토 후 저장하며, 사용자의 명시적 캘린더 요청은 모델의 구조화 작업을 서버가 검증하여 직접 반영한다.
- 자료 수집 결과는 실제 출처와 연결하고, 생활관리 지침의 적용 대상과 약재 기원 정보의 한계를 기록했다.
- Windows에서 SQLite 연결이 닫히지 않던 문제를 찾아 context manager에서 명시적으로 닫도록 수정했다.
- 브라우저 검증에서 발견한 favicon 요청 오류를 수정했다.
- 출처 ID 검증, 사용자 발언 인용, 세션 분리·삭제, 실패 시 부분 대화를 저장하지 않는 동작을 자동 테스트했다.
- 체크인·목표·검색·예약 준비·일정은 실제 SQLite에 저장한다. 외부 예약을 접수했다고 표시하지 않으며 사용자 확인 후 연결 일정을 생성한다.
- 새 대화 생성·전환·이름 변경과 대화별 상태 복원을 추가했다. 기존 SQLite 세션을 마이그레이션하여 기존 대화를 유지한다. 생활기록과 찾아본 자료는 상태를 기억하는 오른쪽 사이드바로 표시하며 모바일에서는 패널로 펼친다.
- 사용자의 최종 범위에 맞춰 Codex 대화·고문헌 탐색·원문 위치·생활관리·병원 방문 준비로 시연을 정리했다. 병원 카드는 이름·주소·추천 근거와 전화·예약 링크를 중심으로 표시하고, 개인 방문 일정 초안을 바로 저장할 수 있다. 지도·경로 코드, 키 파일 읽기, SDK 설정, 관련 화면과 테스트는 제거했다.
- 자체 월별 캘린더와 날짜별 목록, 달력 안의 Luna High 대화를 추가했다. 일정과 예약 준비·시간 변경·확정 보고·로컬 취소를 대화로 실행하며 대상 ID·세션 소유권·원문 요청을 검증한다. DB 연결은 스레드별로 재사용하여 여러 변경과 대화 저장을 함께 커밋하거나 되돌린다. 외부 캘린더 링크를 제거하고 `.ics`는 유지했다.
- 한의사 지침을 개인 목표에 연결하고 환자 발언 원문·날짜·수치를 검증한 14일 내원 리포트를 추가했다. 누락은 기록 없음, 같은 날 상충하는 발언은 판정 보류로 보존한다.
- 가독성 피드백에 따라 대화창을 넓히고 입력·원문·기존 기록을 접었다. 실제 Luna High가 한자 인용에 한국어 해석을 생성하고 해석과 검증된 원문을 별도로 저장한다.
- 사용자 요청으로 데모를 의료진 진단·지침에 기반해 Hanui가 먼저 질문하는 흐름으로 변경했다. 의료진 맥락과 환자 발언을 별도로 저장하고 질문만으로 환자 사실을 만들지 않는다. 실제 첫 질문만 있는 대화와 합성 14일 리포트 예시를 분리했다.
- 확장 검증은 자동 테스트 76개와 합성 검색 결과를 사용하는 화면 검증, 실제 OpenAI 검색·대화·자체 캘린더 8턴·지침 4턴·한국어 해석 1턴·선행 질문과 환자 답변 검증을 구분해 기록했다.

이 문서는 개발 과정의 요약이며 전체 Codex 대화 로그를 대신하지 않는다. 실제 제출 시스템이 요구하는 Codex 사용 기록의 형식과 범위는 해당 안내에 맞춘다. 제출 기록에서 개인정보와 인증정보를 제외한다.

## 저장소 반영

로컬 Git을 초기화하고 커밋·push하며 개발 이력을 남긴다. 제출 플랫폼의 실제 안내에 따라 저장소 주소와 최종 SHA를 제출한다. 커밋 이력은 재작성·삭제하지 않는다.

## 자동 검증

`python -m unittest discover -s tests -v`: **36개 통과**.

기존 16개는 대화·기억의 원문 연결, 세션 분리, DB 재접속, 약재 주제 전환, 출처 ID, 모델 실패의 원자성, AI 대화 직접 실행, HTTP Host·Origin을 확인했다.

추가 17개는 체크인 수정과 미입력 값 보존, 범위 밖·NaN·무한 값 거부, 7일 평균, 목표 완료의 중복 방지, 일정 수정·삭제와 세션 소유권, 시간 겹침, UTF-8 ICS 줄 접기·구분자 escaping, 예약 준비·외부 확인·중복 확정 방지·취소, 모든 DB 기록의 cascade 삭제, 검색 실패 시 미저장, DB 필터, 위험 URL 제외, 대화의 체크인 수치 초안과 미저장 상태를 확인했다.

원문 검색 3개는 태그에 없는 본문 용어 탐색, 고문헌·현대 자료 동시 검색, 검색어 SQL escaping, Luna가 고른 키워드에 따른 탐색, 원문에 없는 인용 거부, 본문 문자 위치 계산, 인용의 재접속 복원을 확인했다.

## 실제 OpenAI 연결

현재 계정의 ChatGPT 로그인, `gpt-6-luna`, `high`, OpenAI provider로 확인했다.

- `python live_smoke.py`: 2턴에서 수면 5시간의 원문 기억, 이전 맥락 조회, DB의 실제 미병 자료 출처를 반환했다. 전문 검색 키워드 분석 추가 후 실행은 약 57초였다. 단일 실행이며 응답시간 보장이 아니다.
- 직접 검색: OpenAI 웹 검색 실행 이벤트를 확인한 뒤 강남역 인근 한의원의 공식 정보와 네이버 예약 링크를 가져왔다. 실제 예약이나 슬롯 확인은 하지 않았다.
- 대화 자동 검색: “강남역 근처 한의원 찾아줘. 역에서 가까운 곳이면 좋겠어.”라는 합성 발언에서 `hospitals` 작업이 생성되고 실제 검색이 실행되어 검색 기록과 병원 원문 URL을 DB에 저장했다.
- 체크인 초안: 실제 Luna High가 수면 6시간·커피 2잔의 발언에서 체크인 작업을 반환했다. 검토 전 체크인 DB는 비어 있음을 확인했다.
- `python live_search_smoke.py`: 최신 설정으로 병원 검색 1건·일반 웹 검색 2건을 반환했다. 검색 결과를 실제 DB에 저장했고 예약 접수는 실행하지 않았다.
- `python live_retrieval_smoke.py`: 고문헌과 현대 자료 통합 2턴 검증, 48.6초. 황제내경의 ‘治未病’ 및 ‘食飲有節，起居有常，不妄作勞’ 인용을 DB 본문·장절·문자 위치와 대조했다. 다음 턴에는 신농본초경의 인삼 원문을 인용하고, 실제 OpenAI 검색으로 NIH NCCIH 인삼·약물 상호작용 공식 자료 2건을 찾아 역사 기록과 현대 근거를 비교했다.

로컬 결과: `.runtime/live-check.json`, `.runtime/web-live-check.json`, `.runtime/chat-search-check.json`, `.runtime/action-live-check.json`, `.runtime/search-live-check.json`. 인증정보는 읽거나 복사하지 않는다.

`python ui_smoke.py`: 실제 로컬 서버에서 샘플 대화, 기억, 원문 dialog, 재접속, 약재 조회, HTML 텍스트 처리, 390px 모바일 가로 넘침, 전체 삭제를 확인했다.

`python ui_care_smoke.py`: 별도 임시 서버·DB와 명시된 합성 검색 결과로 다음을 확인했다.

- 체크인 저장과 평균, 목표 완료, 한의학 DB 필터와 출처.
- 대화 안의 병원 검색 결과와 후기의 HTML 텍스트 처리. AI 실행 전 동의창이 없음을 확인.
- 예약 준비만 저장했을 때 일정 미생성.
- 외부 예약 확정을 사용자 확인한 뒤 일정 생성, 취소 시 연결 일정 제거.
- 개인 일정 생성, `.ics` 다운로드, Google 링크에서 개인 메모 제외.
- 대화 안의 웹 결과와 원문 인용·위치, 재접속 복원, 모든 기능의 모바일 화면, JSON 내보내기, 전체 기록 삭제.

브라우저 콘솔 오류는 없었다. 1440×1024·390×844 화면을 확인했다. 테스트 후에도 사용자의 원래 브라우저 프로필을 사용하지 않는다.

## 자료 검증과 범위

지식 DB 42건: 기존 요약 7건 + 30종 약재 기원 요약 + NIH NCCIH 5건. 약재 이름은 총 33종이다. 추가 기원은 다운로드된 한국한의약진흥원 2025년 공고 첨부 품목표와 대조했다. NCCIH 원문 5개를 실제 내려받았으며 해시와 수집 정보는 manifest에 기록한다.

고문헌 원문 57건을 추가하여 총 99건. 동의보감 수록 원문, 황제내경 소문 제1권, 신농본초경의 고정 Wikisource 판본에서 약 4.6만 자를 정리했다. 실제 다운로드 6개 판본의 SHA-256을 확인하며, 원문에 존재하지 않는 절은 채워 넣지 않는다. 범위와 전사 품질의 한계는 [고문헌 자료](CLASSICAL_SOURCES.md)에 기록한다. 수집·정리는 사용자 요청에 따라 Luna xhigh 서브에이전트가 수행했고 원문의 서문 저자와 수록 절·항목 위치는 주 에이전트가 대조하여 수정했다.

이는 임상 검증, 실제 사용자 개선 효과, 대형 RAG 검색 평가, 전국 병원 정보 완전성 검증이 아니다. 검색된 웹 정보·후기를 모두 자동으로 사실 검증하는 시스템도 아니다. 확정된 슬롯이나 예약 접수를 가장하지 않으며 외부 예약 완료는 사용자가 확인한다. 개인별 진단·처방·약재 구매, Google OAuth 쓰기, 공개 서비스 인증은 포함하지 않는다.

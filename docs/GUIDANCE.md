# 한의사 지침과 내원 전 리포트

생활 관리 → **한의사 지침 입력**에서 입력자 표기, 시작일, 생활 지침 원문을 저장한다. 쉼표·줄바꿈으로 나눈 항목은 기존 개인 목표에 연결된다. 원문과 입력 시각, 각 항목의 문자 위치를 함께 보존한다. 현재는 로컬 입력 기능이며 입력자의 한의사 신원을 인증하는 병원 포털은 아니다.

예: `취침 23시 전, 찬 음식 줄이기, 커피 1잔 이하, 점심 후 산책 10분`.

## 대화 기록과 코칭

현재 계정의 OpenAI `gpt-6-luna` / `high`가 현재 환자 발언에서 날짜·생활 수치·불편감·지침 실천 보고 후보를 추출한다. 서버는 **사용자 역할의 실제 메시지, 해당 대화 소유권, 정확한 인용 문자열·위치, 날짜, 발언의 수치**를 다시 확인한 뒤 저장한다. 숫자와 시간은 모델이 만든 요약 대신 발언에서 재계산한다.

“어제 새벽 1시에 잤어”는 어제의 01:00 기록으로 저장되어 23시 이전 지침과 비교된다. 새벽 시각은 밤의 연속선에서 비교한다. “오늘 점심 후 15분 산책했어”는 점심 후 10분 목표와 비교한다. 일반 산책은 점심 후 산책으로 추정하지 않는다.

“찬 음식 줄이기”에는 임의의 허용 횟수를 만들지 않는다. “오늘 찬 음식 줄였어”처럼 직접 실천 여부를 보고한 경우에만 판정한다. 단순히 먹었다는 발언은 미판정이다. 가정·질문·미래 계획·타인의 발언, 날짜가 불명확한 평소 습관을 하루의 실천으로 채우지 않는다. 같은 날 서로 다른 수치가 있으면 상충 상태로 보류한다. 생활 관리의 최근 발언에서 잘못 추출된 기록을 **제외**할 수 있으며 원래 대화는 보존된다.

## 14일 집계와 원문 확인

**내원 리포트**에서 종료일을 선택하면 당일을 포함한 14일을 집계한다. 지침 시작 전·종료 후 날짜는 지침 기간 밖이다.

| 상태 | 실천율 분모 |
|---|---|
| 준수 / 미준수 | 포함 |
| 기록 없음 | 제외 |
| 미판정 / 상충 기록 | 제외 |
| 지침 기간 밖 | 제외 |

따라서 14일 중 8일 기록, 그중 6일 준수이면 **6/8 = 75%, 기록 없음 6일**이다. 기록이 없다고 미준수로 계산하지 않는다. 수면 시간·취침 시각은 각 주의 판정 가능한 기록일 평균만 표시한다. 식사 발언과 식사 지침의 직접 실천 보고는 원문으로 보여준다. 동일 날짜의 상충 수치는 평균에 섞지 않는다.

각 집계·추이·불편감에는 **근거** 링크가 있다. 실제 발언 날짜, 말한 시각, 본문 문자 위치, 인용 구절과 전체 메시지 하이라이트를 확인하고 원래 대화로 돌아갈 수 있다. 기록 없음은 해당 기간·항목의 조회 결과로 설명하며 존재하지 않는 환자 발언을 붙이지 않는다. 기존 일반 목표 체크박스나 수동 체크인을 환자 대화 원문처럼 보고하지 않는다.

인쇄·PDF에서는 앱 주변 UI를 제외하고 A4 리포트를 출력한다. 예시의 네 지침·8일 기록은 **1페이지**이며 원문으로 돌아가는 링크가 PDF에 남는다. 지침 수·문장 길이가 크게 늘면 출력 페이지 수가 달라질 수 있다.

## 저장 및 검증

SQLite `.runtime/hanui.sqlite3`에 `guidance_plans`, `guidance_instructions`, `patient_observations`를 추가한다. 지침 원문 → 개인 목표 → 검증한 환자 메시지의 연결을 보존한다. 지침 종료는 과거 리포트를 지우지 않는다. 대화 삭제는 관련 지침·발언을 함께 삭제한다. 개인 자료와 생성된 PDF는 Git에 올리지 않는다.

```powershell
python -m unittest discover -s tests -v
python ui_guidance_smoke.py
python live_guidance_smoke.py
```

UI 검증은 격리된 합성 자료로 75% 집계, 6일 기록 없음, 모든 주장 근거, 원문 이동, 대화 분리, 모바일·대비, HTML escaping, A4 한 페이지와 PDF 링크를 확인한다. 실제 Luna High 검증은 4턴에서 취침·커피·산책·식사 지침 실천·수면 시간·불편감 추출과 가정 질문의 미기록을 확인했다(45.8초, 단일 실행).

2주 기록을 기다리지 않고 화면을 시연하려면 다음 명령으로 **별도의 합성 데모 대화**를 생성한다. 모델 호출 없이 준비하는 예시이며 각 발언과 지침에 합성 표기가 있다. 기존 대화는 수정하지 않는다. 다시 실행하면 새 예시 대화가 생긴다.

```powershell
python seed_guidance_demo.py
```

출력된 주소를 열고 내원 리포트를 선택한다. 새 대화에서는 실제 Luna High로 지침 입력과 대화 기록을 확인할 수 있다.

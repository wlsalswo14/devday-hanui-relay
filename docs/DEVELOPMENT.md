# 개발 범위와 자료 출처

기록일: 2026-10-09.

|---|---|

기존 Hanui RAG 시스템의 코드는 이 저장소에 가져오지 않았다. 현재 자료 검색은 소규모 seed의 태그·검색어 비교 방식이다.

## Codex 활용과 검토

- 구현과 자료 수집에는 OpenAI 모델만 사용했다.
- 서비스의 대화 모델은 기존 ChatGPT 로그인으로 호출하는 GPT-6 Luna, 추론 강도 high다.
- 병원·공개 후기·웹 검색도 같은 Luna High와 OpenAI 웹 검색으로 실행한다. 다른 제공자의 AI나 서브 에이전트로 전환하지 않는다.
- 일반 대화는 검색·셸·플러그인 없이 동작하며, 외부 검색은 명시적 요청에서만 활성화한다. 기록 변경은 검토 가능한 초안과 사용자 저장으로 처리한다.
- 자료 수집 결과는 실제 출처와 연결하고, 생활관리 지침의 적용 대상과 약재 기원 정보의 한계를 기록했다.
- Windows에서 SQLite 연결이 닫히지 않던 문제를 찾아 context manager에서 명시적으로 닫도록 수정했다.
- 브라우저 검증에서 발견한 favicon 요청 오류를 수정했다.
- 출처 ID 검증, 사용자 발언 인용, 세션 분리·삭제, 실패 시 부분 대화를 저장하지 않는 동작을 자동 테스트했다.
- 체크인·목표·검색·예약 준비·일정은 실제 SQLite에 저장한다. 외부 예약을 접수했다고 표시하지 않으며 사용자 확인 후 연결 일정을 생성한다.
- 확장 검증은 자동 테스트 33개와 합성 검색 결과를 사용하는 화면 검증, 실제 OpenAI 검색과 대화 자동 검색을 구분해 기록했다.

이 문서는 개발 과정의 요약이며 전체 Codex 대화 로그를 대신하지 않는다. 실제 제출 시스템이 요구하는 Codex 사용 기록의 형식과 범위는 해당 안내에 맞춘다. 제출 기록에서 개인정보와 인증정보를 제외한다.

## 저장소 반영

로컬 Git을 초기화하고 커밋·push하며 개발 이력을 남긴다. 제출 플랫폼의 실제 안내에 따라 저장소 주소와 최종 SHA를 제출한다. 커밋 이력은 재작성·삭제하지 않는다.

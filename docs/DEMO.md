# 4분 데모

핵심: **한의사 지침 → 지속 대화 → 고문헌 DB 전문 탐색과 원문 검증 → 개인 생활관리 → 근거가 붙은 내원 전 리포트 → 병원 방문 준비**. 현재 ChatGPT 로그인으로 실행하는 OpenAI Codex Luna High가 대화를 연결한다.

## 사전 준비

`python server.py --port 8765`로 실행한다. `python seed_guidance_demo.py`의 주소에 2주 예시 대화가 준비되며 **합성 데모·실제 환자 자료 아님**이 명시된다. 이미 생성한 예시는 `.runtime/guidance-demo.json`에서 확인한다. 대화 목록에서 실제 Luna High 검증용 새 대화와 합성 2주 예시를 구분한다. 합성 기록을 모델이 2주간 관찰한 결과라고 소개하지 않는다.

## 0:00~0:35 — 한의사의 지침을 개인 목표로

새 대화 → 생활 관리 → 한의사 지침 입력. `취침 23시 전, 찬 음식 줄이기, 커피 1잔 이하, 점심 후 산책 10분`을 저장한다. 개인 목표 네 항목과 입력 원문·날짜를 보여준다. 현재는 텍스트 입력 데모이며 병원의 환자 시스템과 자동 연동된 것으로 소개하지 않는다.

## 0:35~1:15 — 대화에서 지침 대비 기록과 코칭

“어제 새벽 1시에 잤어. 어제 커피 두 잔 마셨어.”를 입력한다. Luna High의 추출 → 서버의 실제 발언·날짜·수치 대조 → 지침과 비교한 짧은 코칭을 보여준다. 기록의 원문을 눌러 환자가 실제로 말한 문장과 날짜를 확인한다. 사이드바를 접거나 펼쳐 기록과 찾아본 자료를 보여준다.

## 1:15~1:55 — 고문헌을 전문 탐색

“황제내경에서 미병과 일상생활 관리에 대해 DB 원문을 찾아줘.”를 입력한다. Luna의 키워드 → SQLite 원문 전체 탐색 → 관련 문장 정리 → 정확한 인용 대조를 설명한다. 문헌명·장절·단락·문자 위치·고정 판본 원문을 확인한다. 총 99건은 현대 요약 42건과 고문헌 원문 57건이다. 고대 기록과 현대 임상 근거를 구분한다.

## 1:55~3:00 — 핵심 장면: 한의사용 내원 전 리포트

목록에서 **합성 데모 · 2주 지침 관리**를 열고 내원 리포트를 선택한다. “14일 중 8일 기록, 6일 준수, 실천율 75%, 기록 없음 6일”을 보여준다. 기록 없는 날을 실패나 성공으로 채우지 않는 점을 설명한다. 수면·식사 추이와 환자 불편감의 근거를 눌러 실제 저장된 발언·날짜·본문 위치를 확인하고 원래 대화로 이동한다. 지침 제목은 입력 원문으로 이어진다.

인쇄·PDF 버튼으로 네 지침의 예시가 A4 한 페이지로 정리됨을 보여준다. PDF의 원문 링크도 같은 대화로 돌아온다. 리포트는 검증된 자기보고 자료의 요약이며 임상 효과를 입증한 결과로 소개하지 않는다.

## 3:00~3:40 — 다음 방문 준비

실제 Luna 대화로 돌아가 “강남역 주변 한의원 찾아줘. 이름, 주소, 추천 근거와 전화·예약 링크를 알려줘.”를 입력한다. 간결한 병원 카드와 공개 정보 근거를 보여준다. 검색 지연 시 저장된 직전 결과와 확인 시각을 보여준다.

병원 선택 → 예약 준비 → 자체 캘린더의 희망 방문 시간을 보여준다. 실제 접수는 전화·예약 페이지에서 이루어지며 준비 기록과 사용자의 확정 보고를 구분한다. “내일 오후 3시에 산책 30분 넣어줘”처럼 일정 추가·수정·삭제도 대화로 처리한다. `.ics` 내보내기는 유지한다. 외부 예약 없이 실제 병원 확정을 가장하지 않는다.

## 3:40~4:00 — 구현 근거

단위 테스트 69개, 실제 Luna 지침 대화 4턴, 자체 캘린더 8턴, 원문 검증과 모바일 UI·A4 PDF 검증을 제시한다. 우선 검증할 사용자 과제는 한의사의 내원 전 기록 확인 시간, 환자의 출처 확인 성공률, 기록 누락의 가시성이다. 실제 환자 개선 효과를 이미 얻었다고 주장하지 않는다.

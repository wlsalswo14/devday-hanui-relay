# 고문헌 DB 연결

기존 환자 기록 SQLite와 외부 고문헌 DB를 분리합니다. 외부 폴더를 복사하거나 Git에 올리지 않습니다.

연결 폴더에는 다음 파일이 필요합니다.

- `data/kmm.sqlite3`: 문헌 메타데이터와 정본 원문 행
- `data/v2/search.sqlite3`: `kmm-index-v2.1` 전문 검색 인덱스
- `data/term_map.json`: 선택 사항, 한국어·한자 검색어 확장

환경 변수 `HANUI_KNOWLEDGE_ROOT`에 폴더 경로를 설정하거나, 로컬 `.runtime/knowledge-db.json`에 `{"root":"폴더 경로"}`를 저장한 뒤 서버를 재시작합니다. JSON의 Windows 경로 역슬래시는 이스케이프해야 합니다. 환경 변수가 우선입니다. 설정이 없으면 기존 소량 자료를 사용합니다. 연결 설정이 잘못되면 서버 시작 시 오류를 표시합니다.

에이전트가 정한 검색어로 FTS5 인덱스를 조회합니다. 검색어별 최대 80개 후보를 순위 합산하고 제목 일치를 우대합니다. 형태소 인덱스의 접두어 검색과 용어 사전 확장을 사용하며, 별도의 임베딩·재순위 AI 모델은 실행하지 않습니다. 최종 후보만 원본 DB에서 읽어 한자 원문과 국역문을 대조합니다. 불일치 시 답변에 사용하지 않습니다.

검색 결과에는 문헌명, 절 경로, 원문 행 ID, 판본, 출처 URL, 라이선스를 보존합니다. 인용은 기존 문자열 대조 검증과 에이전트의 한국어 해석을 거칩니다. 원본 DB의 국역은 자료 화면에서 원문 이해를 돕는 자료이며, 에이전트가 생성한 해석과 구별됩니다. 라이선스는 원본 DB 메타데이터를 표시하므로 해당 데이터의 실제 이용 조건은 별도로 확인해야 합니다.

자료 화면의 초기 목록은 외부 문헌 40개 발췌를 보여줍니다. 검색하면 전체 인덱스를 조회하되 한 번에 최대 100개 결과로 제한합니다. 대화에서는 원문 자료를 우선 제공하고 관련 현대 자료가 있으면 한 자리를 배정합니다. 외부 검색 결과가 없으면 기존 자료를 조회합니다. 전체 DB를 매 대화마다 메모리에 적재하지 않습니다.

`/api/config`의 `classical_db`에서 연결 여부, 문헌·행·발췌 수, 인덱스 버전과 파일 크기를 확인할 수 있습니다. 로컬 절대 경로나 인증정보는 제공하지 않습니다. `knowledge_count`는 기존 자료와 외부 발췌 합계이며 고유 문헌 수가 아닙니다.

검증: `python -m unittest discover -s tests`. 외부 원문 변조·행 누락 차단, 읽기 전용 접근, 인용 문자열 검증 및 환자 기록 분리를 검사합니다.

# 4분 데모

핵심: “몸이 불편한데 어디서부터 정리할지 모르겠을 때, 대화 속 생활 맥락을 기억하고 근거 확인과 다음 행동까지 연결한다.”

## 0:00~0:40 — 일상으로 시작

Luna High 모드에서 “요즘 5시간 정도 자고 낮에 피곤해. 커피는 하루 2잔 마셔.”를 입력한다. 원문에 연결된 생활기록을 보여준다. “아까 내가 몇 시간 잔다고 했지?”로 기억을 확인한다.

상단 ‘새 대화’로 별도 대화를 만들고 목록에서 이전 대화를 다시 연다. 기억과 생활기록이 대화별로 보존되는 모습을 보여주고 ‘기록·자료’로 오른쪽 사이드바를 접거나 펼친다.

## 0:40~1:20 — 관련 자료를 확인

“황제내경에서 미병과 일상생활 관리에 대해 어떤 말을 했는지 DB 원문을 찾아줘.”를 입력한다. Luna의 키워드 → DB 전문 탐색 → 관련 항목 정리와 정확한 원문 인용 흐름을 설명하고 장절·단락·문자 위치·판본 원문 링크를 연다. “인삼 관련 고문헌과 현재 NIH NCCIH 공식 자료를 웹에서 찾아 비교해줘.”로 고문헌과 현대 자료를 구분하는 모습을 보여준다.

## 1:20~2:00 — 기록에서 관리로

대화가 제안한 체크인 초안을 확인해 저장하거나 생활 관리에서 오늘의 수면·스트레스·불편감을 기록한다. 7일 평균과 수면 그래프, “점심 후 10분 산책” 목표 완료를 보여준다. 점수는 자기보고 기록이며 미병 진단 점수가 아님을 짧게 설명한다.

## 2:00~3:00 — 병원 찾기

“강남역 근처 한의원 찾아줘. 역에서 가까운 곳이면 좋겠어.”를 입력한다. 같은 대화 안에 표시되는 병원·후기 카드와 원문 URL, 확인 가능한 전화·예약 링크를 보여준다. 공개 후기를 찾지 못했다면 그 상태를 그대로 설명한다. 네이버의 비공개 후기를 가져왔거나 후기만으로 진료 역량을 평가했다고 말하지 않는다.

검색이 느리면 이미 DB에 저장한 직전 검색 결과를 보여주고 검색 시간에 관한 한계를 설명한다. 샘플 모드는 모델·웹 검색을 실행한 척하지 않는다.

## 3:00~3:40 — 다음 행동과 일정

병원 선택 → 예약 준비 저장 → 전화·예약 페이지 연결을 보여준다. 준비 상태에서는 일정이 생기지 않는다. 실제 병원 확정은 외부에서 받는 구조임을 설명한다. 확정·취소 흐름은 `ui_care_smoke.py`의 **명시된 합성 병원 데이터**로 검증했다. 실제 접수 없이 실제 병원의 예약 확정을 가장하지 않는다.

개인 일정을 하나 저장하고 `.ics` 내보내기와 Google Calendar 추가 링크를 보여준다.

## 3:40~4:00 — 증거와 다음 검증

현재 계정의 OpenAI Luna High, 현대 자료 42건 + 고문헌 원문 57건(총 99건), 자동 테스트 39개, 실제 대화·검색 검증을 제시한다. 실제 사용자 검증·임상 효과는 아직 주장하지 않는다. 다음 검증은 생활기록 정리 시간, 출처 확인 성공률, 방문 준비의 누락 감소를 측정하는 사용자 과제다.

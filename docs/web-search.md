# 웹검색

메인 Gemma가 웹 작업을 선택하면 별도 Gemma 에이전트가 검색 필요 여부와 공개 검색어를 결정한다. 검색을 선택했을 때 네이버 공개 검색 페이지에서 실제 제목·링크·요약을 읽고, 그 관찰 결과를 에이전트에 전달한다. 별도 검색 API 키나 화면에 보이는 브라우저 창은 필요하지 않다. 검색 결과 페이지의 요약을 사용하며 링크 대상의 본문 전체를 읽었다고 주장하지 않는다.

검색 결과의 실제 서비스명을 응답에 표시하고, 출처 3개를 먼저 보여주며 나머지는 펼쳐볼 수 있다. 공개 링크만 받아 광고·로그인·내부 주소·검색 메뉴를 제외한다. 검색이 실패하거나 검증 가능한 링크가 없으면 성공으로 처리하지 않는다. 요청을 취소하면 진행 중인 검색 자식 프로세스를 종료하고 결과를 버린다. 개인 기록·의사 지침을 검색어로 보내지 않도록 에이전트에 지시한다.

2026-10-10: 기존 Google 자동 검색은 `/sorry/index` CAPTCHA로 차단되는 것을 확인했다. Google 도움말은 자동화 트래픽이나 공유 네트워크의 트래픽이 원인일 수 있다고 설명하지만 이 PC에 적용된 내부 판정 이유는 확인할 수 없다. CAPTCHA 우회를 추가하지 않고 정상 응답하는 네이버 검색을 기본 경로로 연결했다. 명시적인 브라우저 조작 기능은 기존 Playwright MCP를 유지한다.

임시 환자 DB와 실제 Gemma·Chromium 화면에서 “질병관리청 수면 건강 안내”와 “서울 강남역 한의원” 질문의 검색→답변→출처 링크 표시를 확인했다. 마지막 실측은 각각 9.58초와 9.86초였다. 직접 검색 도구 호출은 세 가지 질문에서 0.6~0.8초였다. 소수의 실측이며 보장 시간이 아니다. 검색 결과의 모든 사실·병원 운영 정보가 확인된다는 의미는 아니다. 공개 검색 페이지 구조나 접근 정책 변경 시 파서 보완이 필요할 수 있다.

Google 안내: https://support.google.com/websearch/answer/86640

검증: 자동 테스트 148개 통과. 최종 검색 관련 변경 후 검색·브라우저 테스트 21개 재실행 및 실제 앱 화면 검증.

# Hanui Relay

일상을 이야기하면 생활 맥락을 기억하고, 한의학 정보를 찾아보고, 생활 관리와 병원 방문 준비까지 이어가는 로컬 데모.

## 구현된 흐름

| 기능 | 실제 동작 |
|---|---|
| 지속 대화 | 현재 ChatGPT 로그인으로 **GPT-6 Luna / high** 호출. 이전 대화·자기보고 생활기록·체크인·목표·일정을 함께 참고한다. |
| 한의학 DB | 현대 자료 요약 **42건** + 고문헌 원문 **57건**, 총 **99건**을 SQLite에 가져온다. Luna가 질문·앞선 대화에서 키워드를 정하면 원문·한국어 독해·항목을 전문 탐색하고 관련 문장을 정리한다. |
| 원문 인용 | Luna가 고른 인용을 DB 본문과 대조해 정확한 문자열인지 확인한다. 문헌명·장절·단락·본문 문자 위치·고정 판본 원문 링크를 대화에 함께 표시한다. |
| 생활 기록 | 수면·식사·활동·카페인·스트레스·불편감·목표에 관한 자기보고 발언을 원문과 연결해 기억한다. 항목 삭제와 전체 기록 내보내기가 가능하다. |
| 매일 관리 | 날짜별 체크인 저장·수정·삭제, 최근 7일 평균과 수면 그래프, 생활 목표와 일별 완료 기록. 대화의 수치 기록을 체크인 초안으로 제안하며 사용자가 확인 후 저장한다. |
| 병원·후기 검색 | Luna High의 **OpenAI 웹 검색**으로 실제 병원·공식 정보·공개 후기를 찾는다. 지역과 방문 조건으로 비교하며, 찾지 못한 후기·예약 슬롯·평점은 만들지 않는다. |
| 예약 준비 | 검색한 병원의 전화·확인된 예약 링크로 연결한다. 희망 일시와 방문 메모를 DB에 저장하고, 사용자가 병원의 확정을 확인하면 방문 일정을 자동 생성한다. |
| 캘린더 | 일정 생성·수정·삭제, 겹치는 시간 안내, 예약 취소 기록과 연결 일정 삭제, `.ics` 내보내기, Google Calendar 추가 링크. |
| 현대 웹 자료 | 대화에서 Luna High가 검색어를 정하고 실제 OpenAI 검색을 수행한다. 결과·출처는 같은 대화에 표시하고 검색 기록을 저장한다. 별도 웹·병원 검색 메뉴는 없다. |

**예약 준비는 병원에 접수된 상태가 아니다.** 병원 전화·예약 페이지에서 실제 접수와 확정을 완료한다. Google Calendar 링크에서도 사용자가 저장을 완료한다. 병원 예약 API와 Google OAuth는 사용하지 않는다. 이 범위는 사용자가 선택한 “전화·예약 링크 + 캘린더 내보내기” 방식이다.

## 실행

Python 3.11 이상. 서버·DB·자료 다운로드에는 Python 표준 라이브러리만 사용한다.

```powershell
python server.py --port 8765
```

<http://127.0.0.1:8765>를 연다. `start.ps1`로도 시작할 수 있다. 로컬 loopback 전용으로, 공개 배포용 로그인·사용자 권한은 포함하지 않는다.

AI는 공식 Codex CLI의 기존 ChatGPT 로그인을 사용한다.

```powershell
codex login status
```

`HANUI_CODEX_EXECUTABLE`로 공식 실행 파일 경로를 지정할 수 있다. 요청 모델 `gpt-6-luna`, reasoning effort `high`, provider `openai`를 고정하며 다른 AI나 모델로 자동 전환하지 않는다. 계정의 모델 접근 권한·검색 지원·사용량에 따라 오류가 표시될 수 있다. 별도 API 키는 필요하지 않으며 인증정보를 읽거나 복사하지 않는다.

`codex exec --ignore-user-config --ephemeral`로 호출한다. 셸·파일 실행 도구·앱·플러그인·서브 에이전트·브라우저는 비활성화한다. 질문 분석과 DB 답변은 웹 검색 없이 실행하고, 대화에서 Luna가 선택한 공개 정보 탐색 작업에 OpenAI 웹 검색을 켠다. 모델은 빈 작업 폴더에서 실행된다. Luna의 키워드를 서버가 SQLite 전문에 적용한 뒤 찾은 자료와 해당 대화 상태를 모델에 제공한다.

## DB와 자료

SQLite 파일은 `.runtime/hanui.sqlite3`다. 서버 시작 시 `data/knowledge.seed.json`과 `data/classics.seed.json`을 검증·가져오고, 자료 파일이 바뀌면 검색 시 갱신한다. 대화, 인용 원문과 위치, 발언과 연결된 기억, 체크인, 목표, 병원 검색, 예약 준비, 일정은 실제 DB에 저장되어 재접속 후 복원된다. 전체 세션 삭제 시 연결된 모든 기록이 삭제된다.

현대 자료 42건은 한국한의약진흥원·BioIN·KCI·NIH NCCIH의 공개 자료를 확인한 자체 요약이다. 약재 기원 목록의 33종은 원료 정보다. 고문헌은 공개 Wikisource 원문을 판본에 고정하여 별도 저장한다. 수록 범위와 이용·출처 정보는 [고문헌 자료](docs/CLASSICAL_SOURCES.md)에 기록한다. 고대의 기록과 현대 임상 근거를 구분한다.

전문 검색은 DB의 원문·독해·제목·장절·태그 전체에 대해 매개변수화한 부분 문자열 검색을 수행한다. 한국어·한문 키워드를 Luna가 고르고 일치도 순으로 최대 8개 항목을 답변에 제공한다. 수록한 원문 범위의 전문 탐색이며 한의학 고문헌 전체를 보유하는 DB는 아니다.

자료 원문 다운로드와 재생성:

```powershell
python refresh_data.py
python refresh_classics.py
```

공식 URL만 내려받는다. 기원 목록 PDF는 확인한 SHA256과 일치해야 하며 자료가 변경되면 재검토를 요구한다. 다운로드 실패 시 기존 seed를 유지한다. 원문 PDF·HTML은 `data/source-documents/`에 로컬 참조용으로 보관하고 Git에서 제외한다. 공개할 출처·수집·해시 정보는 `data/sources.manifest.json`에 기록한다.

## 개인정보와 한계

AI 대화와 정보 검색은 별도 동의창 없이 대화에서 실행한다. 대화·생활기록·체크인·일정 등은 현재 계정의 OpenAI 모델에 전달된다. 일반 대화에서 제안한 기록·목표·일정은 저장 전에 사용자가 검토한다. 예약 확정과 취소는 외부 병원에서 처리한 사실을 사용자가 확인하는 로컬 기록이다.

대화·DB·임시 모델 파일·개인 기록 내보내기는 `.runtime/`에 두며 Git에서 제외한다. Google Calendar 링크에는 제목·시간·장소만 포함하고 방문 메모를 전송하지 않는다. `.ics`와 JSON 내보내기에는 사용자의 메모가 포함된다. SQLite 자체 암호화와 공개 서비스 인증은 없다.

미병·질병·체질의 개인 진단, 증상에 맞춘 약재·처방·복용량 추천, 약재 구매는 제공하지 않는다. 출처 ID·JSON 형식·기억 인용을 검사하지만 의학적 문장의 의미를 임상적으로 보증하는 검증은 아니다. 공개 후기의 접근성과 정확성은 사이트와 검색 결과에 따라 다르며 후기 자체가 진료 역량을 증명하지 않는다.

## 검증

```powershell
python -m unittest discover -s tests -v
python ui_smoke.py
python ui_care_smoke.py
```

브라우저 검증에는 Playwright와 Chrome 또는 Playwright Chromium이 필요하다. 앱 실행에는 필요하지 않다. 확장 UI 테스트는 격리된 DB와 명시된 합성 병원·검색 결과를 사용하므로 실제 예약이 발생하지 않는다.

실제 계정 사용량을 소비하는 합성 대화 검증:

```powershell
python live_smoke.py
python live_search_smoke.py
python live_retrieval_smoke.py
```

실제 대화·검색 검증 결과와 한계는 [검증 기록](docs/VALIDATION.md), 4분 시연 흐름은 [데모 안내](docs/DEMO.md), 기획과 당일 개발의 구분은 [개발 기록](docs/DEVELOPMENT.md)에 정리했다.

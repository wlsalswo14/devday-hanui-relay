## 질의응답 대비

- **차별점**: 일반 기록 앱의 숫자 요약을 넘어 한의사 지침 원문, 환자의 정확한 발언, 고문헌 출처, 내원 준비를 하나의 대화 흐름에서 연결한다.
- **원문 오류**: DB에 없는 인용 문자열은 거부하고 문자 위치를 계산한다. 한국어 의학 해석은 별도 전문가 검토가 필요하다.
- **실사용 검증**: 현재는 합성 화면과 실제 에이전트 연결 테스트다. 환자·한의사의 사용성과 성과를 관찰한 연구는 아직 없다.
- **사업성**: 한의원이 잠재 도입·비용 주체이고 환자가 사용자다. 지침 입력 → 환자 대화 → 내원 전 원문 근거 리포트 검토로 운영하며, 지침 변경·재방문 때 누적 기록을 연결한다. 확인 시간과 반복 질문 감소는 가설이다. 작은 파일럿에서 확인 시간·재사용률·모델 호출 비용을 측정하고, 가격·지불 의사는 별도로 확인한다.
- **예약 범위**: 외부 전화·예약 링크를 제공하고 사용자의 확정 보고를 기록한다. 병원 시스템에 실제 접수하지 않는다.
- **안전 경계**: 진단·체질 판정·처방·약재 효과 판단을 제공하지 않는다. 기록 누락과 상충을 보존하고 원문을 확인하게 한다.

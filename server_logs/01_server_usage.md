## 범위와 해석

- 실제 작업 시작 시각은 별도 기록으로 확인하지 못했다. 00:00 KST는 보수적으로 정한 조회 시작 경계이며 작업 시작 시각이라는 뜻이 아니다.
- 03은 현재 실행 계정에 해당하는 TerminalServices 이벤트만 포함한다. Windows Security 로그는 수집할 수 없었다. 권한이나 감사 설정은 변경하지 않았고, 수집 실패를 접속 0건으로 기록하지 않았다.
- 읽을 수 있는 채널에 일치 이벤트가 없어도 전체 원격 접속이 없었다고 단정할 수 없다. 로그 보존 기간과 세션 시작 전 기록의 공백이 있을 수 있다. 현재 Console 표시는 수집 시점의 상태만 나타낸다.
- 04는 03의 성공 접속·인증·재접속 이벤트 중 실제 출발 IP가 확인된 항목을 중복 제거해 작성한다. 03의 성공 세션에는 출발 IP가 없어 04는 헤더만 있다. 이는 관찰 가능한 성공 IP가 없다는 뜻이며 전체 접속 0건의 증명은 아니다. IP를 추정해 채우지 않았다.
- ACCOUNT_01 이외 계정의 접근 가능 여부와 계정 공유 여부는 확인하지 못했다. 시스템 전체 계정, 다른 사용자 이벤트, 프로세스 목록은 수집 범위에 포함하지 않았다.
- 05의 프로젝트 Python 프로세스와 loopback 수신 상태는 수집 시점의 관찰값이다. 관찰된 프로젝트 작업에서 컨테이너 생성이나 외부 배포는 없었으며 시스템 전체 사용 이력을 조사한 결과는 아니다.
- 비밀번호, 비밀 키, 토큰, 쿠키, 환경 비밀 파일, 프로세스 인자, 전체 명령 기록은 수집하지 않았다. 원본 팀 범위 기록과 가명 대응표는 저장소 밖의 접근 제한 디렉터리에 보관한다.

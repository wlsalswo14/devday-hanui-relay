# 디자인 검증

2026-10-11, 설치된 Chrome을 Python Playwright로 실행해 확인했다.

- 독립 HTML 시안 10개를 1440px, 390px, 320px에서 렌더링했다. 30개 조건에서 가로 넘침과 JavaScript 실행 오류가 없었다.
- 각 시안은 `main` 영역과 자체 SVG 아이콘을 갖고 있다. 렌더링 중 HTTP/API/외부 자원 요청은 0건이었다.
- 갤러리에는 시안 10개가 있고 모든 미리보기 이미지가 정상 로드됐다. 각 시안은 상대 경로로 열리며 비교 갤러리로 돌아가는 링크를 제공한다.
- 데스크톱 화면을 직접 검토해 레일형 대화, 상단 탭 대시보드, 목차형 저널, 다크 대화, 분할 체크인, 가로 정보 띠, 시간축 플래너, 3열 문헌 리더, 모바일 습관 화면, 오른쪽 세로 메뉴가 다르게 배치됐음을 확인했다.
- Orbit의 좁은 화면에서 발생한 5px 가로 넘침은 그리드 열과 입력 필드의 최소 너비를 조정해 수정했다. 생성된 부가 설명은 샘플 생활 기록에 맞게 줄였다.
- `previews/`에는 데스크톱과 모바일 캡처가 있다. 모바일 전체 페이지 캡처는 고정 내비게이션이 중간에 나타날 수 있다. 실제 화면은 스크롤해 볼 수 있다.

생성에는 `gemini-3.8-flash` / `HIGH`를 사용했다. 공급자의 503 및 타임아웃 발생 후 실패한 요청만 출력 분량과 동시 요청 수를 줄여 재시도했다. 원본 생성 응답·스크린샷 참고 자료·검증 JSON은 `.runtime/`에 보관했다. 최종 HTML에는 키, 실제 환자 기록, 모델 호출, DB 연결, 저장 기능이 없다.

자동 검사는 렌더링과 넘침을 대상으로 한다. 접근성 전체 준수나 의료 정보의 정확성을 평가한 결과가 아니다. 모든 건강 수치·발언·문헌 위치는 디자인을 보여주기 위한 샘플이다.

# Prism UI

2026-10-11. Gemini 3.8 Flash HIGH로 생성한 첫 번째 디자인
[`01-prism`](../designs/ten-directions/01-prism.html)을 실제 Hanui 화면에 적용했다.
Codex가 기존 대화·캘린더·리포트 기능에 맞춰 스타일과 접근성을 조정했다.

## 화면

- 기본 사이드바는 72px 아이콘 레일이다. 펼치면 260px 대화 목록이 나온다.
- 대화와 입력창은 최대 860px 너비로 읽기 쉽게 배치한다.
- 밝은 라벤더 배경, 흰색 답변, 보라색 사용자 메시지와 주요 버튼을 사용한다.
- 부가 정보는 작게 표시하고 원문·풀이·인용 위치는 펼쳐 읽는다.
- 캘린더, 자유 작성 리포트, 시스템 지침과 건강 프로필에도 같은 스타일을 적용한다.
- 모바일은 기존 메뉴 서랍을 유지한다. 인쇄 화면은 기존 인쇄 스타일을 사용한다.

변경 전 체크포인트: `design-checkpoint-before-prism-20261011` (`a40cca8`).
스타일 진입점: `static/prism.css`.

## 검증

아래 Playwright 검증은 임시 DB와 모델 대역을 사용했다. 실제 환자 기록이나
외부 모델 응답을 테스트 데이터로 사용하지 않았다.

- `ui_shell_smoke.py`: 아이콘 이동, 대화 삭제, 메뉴 상태 보존, 모바일 키보드 접근.
- `ui_health_platform_smoke.py`: 건강 프로필, 체크인, 리포트 가져오기, 반응형 화면.
- `ui_report_document_smoke.py`: 자유 작성, 저장·복원, 대화별 분리, PDF.
- `ui_prism_smoke.py`: 320·360·390·768·1024·1440px에서 대화·캘린더·리포트
  18개 조건. 긴 답변 스크롤, 원문·풀이 창, 텍스트 대비, 입력창 위치,
  가로 넘침과 브라우저 오류를 확인했다.

모두 통과했다. 로컬 검증 결과와 캡처는 `.runtime/prism-ui-check.json`과
`.runtime/screenshots/prism/`에 보관한다.

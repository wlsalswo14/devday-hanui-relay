## 현장 데모 동선

슬라이드 4에서 실제 Luna 대화 C `http://127.0.0.1:8765/?session=a63cdbff74c6445a91a348fb03da48ed`를 연다. 한의사 입력 기반 첫 질문은 이미 생성돼 있다. 발표자가 `어제 새벽 1시에 잤어. 어제 5시간 잤어.`를 보내고 지침 대비 기록·다음 질문을 확인한다. 응답이 지연되면 기다리며 화면을 설명하되 40초를 넘기기 전 PDF로 돌아간다. 슬라이드 5에서 **다른 대화인 합성 데모 A** `http://127.0.0.1:8765/?session=bd8929175b234f228c99ed212779d184`의 14일 리포트를 연다. 슬라이드 6에서 같은 A의 자체 달력을 연다. PDF는 네트워크 문제에 대비한 오프라인 발표 화면이다.

## 짧은 질의 대비

- “75%는 무엇인가요?” → 합성 14일 중 기록된 8일에서 6일의 지침 준수율이며, 실사용자 개선이나 임상 효과가 아니다.
- “예약을 대신하나요?” → 전화·예약 링크와 준비 기록만 지원한다. 실제 접수는 외부 채널에서 사용자 본인이 한다.
- “원문 검증 범위는?” → DB 인용 문자열과 문자 위치의 일치를 검증한다. 한국어 해석의 임상적 의미까지 자동 보증하지 않는다.

# MVP 검증 기록

검증일: 2026-10-09. 모든 대화 검증에는 합성 입력을 사용했다.

## 자동 테스트

`python -m unittest discover -s tests -v`: **16개 통과**.

확인 범위: 사용자 발언과 원본 메시지 연결, DB 재접속 후 기억 유지, 연속 대화 기억, 약재로 주제 전환, 타인·가정 발언 처리, 세션 분리, 대화·기록 삭제, 모델 입력에 이전 맥락 전달, 모델 실패 시 부분 대화 미저장, AI 전달 동의, 허용되지 않은 출처 ID 차단, 원문에 없는 기억 인용 제외, 빈 DB 처리, HTTP 요청 형식·Origin·Host 검증.

샘플 모드 테스트와 가짜 모델을 사용하는 테스트가 포함되어 있다. 이 통과 수치는 실제 모델의 의학적 성능을 평가한 결과가 아니다.

## 실제 AI 연결

`python live_smoke.py`: 현재 ChatGPT 로그인으로 GPT-6 Luna / high에 합성 대화 **2턴**을 전달했다.

- 첫 발언의 수면시간을 생활기록으로 저장했다.
- 다음 질문에서 이전에 말한 5시간을 다시 확인했다.
- 로컬 DB의 미병 자료 ID를 실제 출처로 반환했다.
- 당시 2턴 검증의 총 경과 시간은 약 11.8초였다. 단일 실행 결과이며 일반적인 응답시간을 보장하지 않는다.

실제 실행 결과 파일은 `.runtime/live-check.json`에 로컬로 보관한다. 계정 인증정보는 읽거나 복사하지 않는다.

## 브라우저

`python ui_smoke.py`: Chrome에서 데스크톱 1440×1024, 모바일 390×844 화면을 확인했다.

대화 전송, 생활기록, 출처 dialog와 원문 링크, 기억 조회, 새로고침 후 복원, 약재 검색, 사용자 HTML 텍스트 처리, 모바일 가로 넘침, 전체 대화·기록 삭제를 확인했다. 브라우저 콘솔 오류는 없었다. 브라우저 상호작용 검증은 샘플 모드로 실행했다.

재실행에는 Playwright와 Chrome 또는 Playwright Chromium이 필요하다. 앱 자체의 실행에는 이 도구들이 필요하지 않다.

## 현재 한계

- 자료 DB는 자체 요약 7건으로 범위가 작고, 검색은 키워드·태그 비교다.
- 모델의 출처 ID·JSON 형식·기억 인용을 검사하지만 답변의 모든 의학적 문장이 원문에 부합하는지 자동으로 보증하지 않는다.
- 생활기록은 사용자 자기보고이며 정정 시 이전 발언과 새 발언을 함께 유지한다.
- 서버는 로컬 loopback 전용이다. 다중 사용자 공개 배포용 로그인·권한은 구현하지 않았다.
- 병원 후기 검색·예약·캘린더·약재 구매는 연결하지 않았다.
